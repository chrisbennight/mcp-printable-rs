# Historical GPU test record

The earlier site-specific observations are not retained in the current public
tree. They do not establish GPU behavior for a current release.

The optional [GPU diagnostic](../scripts/smoke-blender-gpu) can test an exact
Blender image digest on an authorized NVIDIA host. It is not required for
[publication](../docs/releases.md). Record the actual outcome and
keep host identities, device identifiers, and unrelated workload details in
private operational records. Publish only the relevant, sanitized evidence.

This change does not erase older commits or copies of the historical record.
