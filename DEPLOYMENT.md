# Deployment

Use the maintained [installation guide](docs/installation.md) to configure an
independent Linux/amd64 NVIDIA host. It covers authenticated HTTP clients,
workspace storage, container isolation, and reverse-proxy settings.

For operation and delivery, see:

- [Operations and recovery](docs/operations.md).
- [Release qualification](docs/releases.md).
- [CI and its trust boundaries](docs/continuous-integration.md).
- [Scene and render recovery](docs/render-worker.md).

Site-specific deployment configuration and operational evidence belong in
private downstream records, not this public repository. Older versions of this
file are not instructions for a current installation or evidence that a current
release has been deployed. Removing those details here does not erase Git history.
