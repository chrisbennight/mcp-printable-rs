# Retired Gitea configuration

These imported files record the former private lab pipeline. GitHub does not
execute them, and current release policy tests use `.github/workflows` instead.
Do not use this directory to configure the GitHub release or a new installation.
The private endpoints and deployment steps are historical integration details.

See [GitHub CI](../docs/continuous-integration.md) and
[the manual release flow](../docs/releases.md) for maintained guidance.
